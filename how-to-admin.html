Hub admin, step by step

For Avante Travel staff. Every admin tab, one small step at a time.

🔐 Log in to admin

  1. Go to go.avantetravel.co.za/admin-login.html.
  2. Type the admin Password and tap Log In.
You stay logged in for 12 hours, but only in that browser tab. Closing the tab logs you out.

Set a recovery phrase (do this once)

  1. Tap Change Password at the top right.
  2. Type the current password, a new password (at least 6 characters) twice, and a Recovery phrase (optional). (Leaving it blank keeps the old phrase.)
  3. Tap Save Password. Keep the phrase somewhere safe.

Forgot the admin password

  1. On the login page tap Forgot your password?
  2. Type your Recovery phrase and a new password twice.
  3. Tap Reset Password.
No recovery phrase set? Only someone with Netlify access can reset it (Blobs → admin-auth → delete the "admin" key).

👥 Affiliates

Add a new affiliate

  1. Tap the Affiliates tab, then + Add Affiliate.
  2. Type the Affiliate ID (their Stock Network agent GUID; it is also their hub username).
  3. Type their Name and Email (optional). Fill in the email: it's needed for "forgot password".
  4. Type their StockNetwork Site Nr (optional) (needed to match their bookings).
  5. Tick their type: Franchise Affiliate, Property Affiliate or Agent Affiliate.
  6. Set the Revenue share for each channel: % or R flat.
  7. Leave Status on Active. Leave Hook builder access ticked (or untick it).
  8. Add bank details and notes if you have them.
  9. Tap Save Affiliate.
  10. On their row tap Welcome Info. It copies a welcome message. Paste it into an email to them.
Welcome Info always says the password is 0000. That is right for new affiliates only. Admin can't reset an affiliate's password: they use "Forgot your password?" on the login page, which needs their email on file.

Other jobs on this tab

  • Details: all their links (with short links), revenue share, totals and bank details. Copy All copies everything.
  • Edit: change anything except the ID. Then Save Affiliate.
  • Payouts: jumps to Payouts with this affiliate picked.
  • Delete: removes the affiliate and their payout history. Can't be undone.
  • Show only affiliates missing a Site Nr: tick to find the ones to fix.

Make short codes for everyone

  1. Scroll to Generate short codes for every affiliate.
  2. Tap Check now. Read the list.
  3. Tap Generate short codes. Safe to run again; nothing is doubled.

📝 Applications

  1. Tap Applications. Set the email that gets new applications and tap Save (once).
  2. Tap View details on an application.
  3. Contact the person. Set the status to Contacted.
  4. When you say yes, set it to Approved.
  5. Go to Affiliates and add them (it isn't done automatically).
The status is only a label for you. Nothing is emailed to the applicant.

📣 Default Hooks (the offers on every front store)

What they are: the shared offers. Every affiliate hook on "Let admin manage" shows these, with the affiliate's own booking link. Front stores show 6 at a time (1 big, 2 medium, 3 small); the rest take turns every 6 seconds.

Make a default hook (the easy way)

  1. Tap Default Hooks.
  2. Tap Open the hook builder (the teal card).
  3. Make the hook there, then use Load to hub and pick a Default Hook, or + New hook (see the hook builder guide).
  4. Back in admin, refresh. Find that Hook card.
  5. Choose Place on front stores: Rotates with the others, or Fixed: level 1 (big, top), Fixed: level 2, left / right, or Fixed: level 3, left / middle / right.
  6. Tap Save default.
Hooks loaded from the hook builder get their Promotion ends date from the flyer's end date (Flyer to). Change the date in the hook builder: each Publish again sends it to the hub again (and overwrites a date typed in admin). Event flyers arrive as Hook type "Event / festival"; that's expected.

Make or fix a default hook by hand

  1. Need a new card? Tap + Add a hook at the bottom.
  2. Leave Hook type on Property / resort stay.
  3. Tap 🔗 Build booking link. Pick the place (Country › Province › Region › City › Suburb › Property) and the dates. Tap Fill in booking link.
  4. Landing page: tap 🔗 Build landing page link, or 📄 Upload PDF instead (the PDF link still needs Save default).
  5. Picture: tap Upload image (square, under 4 MB). It saves straight away.
  6. Or tap ✨ Auto-build from property or area, type a property or area in Property name or area (or tick places under 🌳 Browse properties by location), tap Generate, pick up to 4 photos and tap Use this draft.
  7. Set the place and end date. Tap Save default.
  8. Optional: tap 📣 Post to Facebook (Avante Travel Page). It goes public straight away.
Links (also a PDF link), place and end date need Save default. Pictures, Auto-build photos and "Clear hook" save straight away. After Clear hook, reload the page before saving that card again. For hooks you make by hand, keep Hook type on Property: "Event / festival" hides the link fields.

The tool cards at the top

The first five work the same: tap Check now, read the list, then tap the button to apply. Nothing changes before that.

  • Check for collapsed booking/landing links → Apply fix: fixes hooks whose booking and landing links are the same.
  • Move saved booking links to the holiday builder → Move to the holiday builder: changes old Stock Network links to holiday builder links with the location tree.
  • Check for misattributed booking links → Apply fix: fixes affiliate hooks that credit the wrong affiliate.
  • Switch every affiliate to "Let admin manage" → Switch to admin-managed: puts every affiliate hook back on your content (theirs is kept).
  • Clear all booking links (red) → Clear all booking links: empties every booking link. There's no second question, so be sure.

Flyer contact info is a form: type the Contact phone number and Contact email address and tap Save contact info.

A hook shows on front stores until its Promotion ends day (South African time). No date? The booking link's check-out date is used. If an affiliate fixes their own hook in a place, theirs wins over yours on their store.

💰 Payouts

  1. Get the revenue report (Stock Network for accommodation, Impact.com for flights).
  2. Tap Payouts and pick the affiliate in Select an affiliate.
  3. Pick the Revenue channel.
  4. Type the Period (for example "October 2026") and the Revenue for this period (R).
  5. Tap Add Revenue Entry. The amount owed is worked out for you.
  6. Get their bank details: Affiliates → Details.
  7. Pay them from your bank (the hub doesn't move money).
  8. Tap Mark Paid on the entry.
Wrong entry? Tap Delete: the totals fix themselves. The share used is the one set when the entry was added.

🏆 Leaderboard

  1. Tap Leaderboard.
  2. Pick Rank by: Total Turnover or one channel.
  3. Read the ranking. Nothing to change here.
This ranking uses the revenue typed in Payouts. The Bookings tab has its own ranking from Stock Network reports.

📥 Bookings (import Stock Network reports)

  1. In Stock Network: Reports → Reservation Detail Listing → export as CSV.
  2. In admin tap Bookings, choose the file, and tap Upload Report.
  3. Read the result: new, updated, unchanged, skipped.
  4. Pick a Category and Period to see the leaderboard and the full breakdown.
Uploading the same dates again is safe. "Skipped" means no affiliate has that Site Nr: fix it in Affiliates → Edit and upload again. Affiliates see these numbers on their My Dashboard.

💬 WhatsApp Messaging (booking alerts)

What it does: when a Stock Network booking email arrives, it's posted to the affiliate's WhatsApp group, and the guest gets a confirmation on WhatsApp.

  1. Tap WhatsApp Messaging, then Edit Routing on the affiliate's row.
  2. Type a Booking email alias, for example jeanl1967+name@gmail.com.
  3. Put that same address as the notification email on the affiliate's Stock Network site.
  4. Add recipients: tap Fetch My Groups and pick a group, and/or type a number and tap Add (up to 10).
  5. Tap Test on each recipient.
  6. Tick which statuses to send: Request, Booked, Confirmed, Paid.
  7. Tap Save Routing.
  8. After the next booking, check Recent Activity (Sent or Failed).

🏡 Property Listings (onboarding forms)

  1. Once: set Notify this email address when a new listing is submitted and tap Save. New listings and agreement answers are emailed there.
  2. Tap Refresh. Tap View on a listing.
  3. Check and correct the details, then tap Save Changes (Send Agreement doesn't save these).
  4. Open it again and fill in Commission / Revenue Share, Listing Duration and the Agreement Terms.
  5. Tap Send Agreement for Acceptance. The person who sent the listing (owner or affiliate) gets an email to accept.
  6. Wait until the Agreement column says Accepted (you also get an email).
  7. Open it again, set Status to Listed, type the StockNetwork Site Nr, and tap Save Changes.
"Listed" can only be chosen after the agreement is accepted. To say no, set Status to Rejected and save. Every status change emails the person who sent the listing.

🗺️ Map & Activities

What it's for: what shows on the Explore Map, the location tree, coordinates, and activities. Use Jump to: at the top to go to a section.

Daily check

  1. Tap Map & Activities.
  2. Read the Overview tiles. Tap any tile that isn't 0 to go and fix it.

Add an activity

  1. Go to Add an activity.
  2. Type the Name, area, price, Latitude, Longitude, booking link and description.
  3. Tap Save activity. Then add photos (up to 12), or tap 🖼️ Find photo.
  4. Check its Location in the list below.

Fix a pin in the wrong place

  1. On the Master map, tap the pin, then Fix coordinates.
  2. Tap Open in Google Maps, right-click the right spot, and click the numbers to copy them.
  3. Paste them and tap Save and place again, then Reload map.

A property with no pin

  1. Go to Find & fix missing coordinates. Pick the list and tap Load properties with no coordinate.
  2. Tap Search, then Use this on the right match.
  3. Can't find it? Tap Can't find it — flag as possibly inactive. Later download the flagged list for Stock Network.

New Stock Network properties

  1. Go to New StockNetwork properties and tap Refresh list.
  2. Tap Dismiss on any you don't want.
  3. Tap Download CSV (ready to re-upload), then upload it under StockNetwork resort list.
  4. Under Location tree, tap Re-run lookup.

Location differences with Stock Network

  1. Go to StockNetwork location review and tap Load flagged properties.
  2. For each row: tap Accept suggested coordinate, or type a District / City2 / State correction and tap Save correction.
  3. Under Corrections to send to StockNetwork, tap Download CSV and email it to Stock Network.

Hide a property from the map

  1. Onboarded (listed) property: go to Properties on the map and untick Show on map.
  2. Stock Network property: on the Master map, tap its pin and tap Hide from map.

🧽 SN Cleanup (make Stock Network match the hub)

What it does: builds a file for Stock Network so Country, Area, City, Suburb and coordinates match the hub's location tree. One step at a time; nothing runs until you press that step's button.

  1. Upload: choose the Stock Network Resort Information export (.csv). Pick Test run the first time (10 properties; you can change the number, up to 500). Tap Next → to go on (← Back goes back).
  2. Find coordinates: tap Start lookups. Decide the Unsure ones (Accept / Reject).
  3. Place in hub: tap Save coordinates and place in hub.
  4. Area choice: keep "Replace with the Avante region" (normal).
  5. Build file: tap Build file. Every check must be ✓ (a "!" is a warning and is OK). Download the file.
  6. Check: load the file into Stock Network, wait one night, come back and tap Check now.
  7. All good? Do it again with Everything in the file.
Google lookups cost money; the screen shows the cost before you start. Any ✗ in the checks means: do NOT load that file into Stock Network.
