Aa Magnifier: make small text big

  1. Tap the round Aa button at the bottom left.
  2. Tap any small text (or a picture). It opens big in a popup.
  3. Tap anywhere to close the popup.
  4. Tap Aa again to switch the magnifier off. Buttons work as normal again.
While the magnifier is on, tapping a button shows its words big instead of pressing it.

🔐 Log in to admin

  1. Go to go.avantetravel.co.za/admin-login.html.
  2. Type the admin Password and tap Log In.
You stay logged in for 12 hours, but only in that browser tab. Closing the tab logs you out.

Search for anything

  1. Tap the magnifying glass at the top, next to AVANTE TRAVEL · ADMIN.
  2. Type what you're looking for in What are you looking for?, for example site nr, resort file or payout.
  3. Tap a result. A tab or a card opens straight away, with a teal border round it.
  4. A result that says How-to guide opens that part of this guide in a new tab.

Set a recovery phrase (do this once)

  1. Tap Change Password at the top right.
  2. Type the current password, a new password (at least 6 characters) twice, and a Recovery phrase (optional). (Leaving it blank keeps the old phrase.)
  3. Tap Save Password. Keep the phrase somewhere safe.

Forgot the admin password

  1. On the login page tap Forgot your password?
  2. Type your Recovery phrase and a new password twice.
  3. Tap Reset Password.
No recovery phrase set? Only someone with Netlify access can reset it (Blobs → admin-auth → delete the "admin" key).

👥 Affiliates

Add a new affiliate

  1. Tap the Affiliates tab, then + Add Affiliate.
  2. Type the Affiliate ID (their Stock Network agent GUID; it is also their hub username).
  3. Type their Name and Email (optional; several: separate with commas). Fill in the email: it's needed for "forgot password". With several addresses, each one gets the reset email.
  4. Type their StockNetwork Site Nr (optional) (needed to match their bookings).
  5. Tick their type: Franchise Affiliate, Property Affiliate, Agent Affiliate or Channel Property Affiliate. The type decides which menus they see in their hub (Franchise or nothing ticked sees everything).
  6. Channel Property Affiliate? Under Channel Property: also give them, tick Activities only when they're ready. It starts off.
  7. Set the Revenue share for each channel: % or R flat.
  8. Leave Status on Active. Leave Hook builder access ticked (or untick it).
  9. Add bank details and notes if you have them.
  10. Tap Save Affiliate.
  11. On their row tap Welcome Info. It copies a welcome message. Paste it into an email to them.
Welcome Info always says the password is 0000. That is right for new affiliates only. Admin can't reset an affiliate's password: they use "Forgot your password?" on the login page, which needs their email on file.

Other jobs on this tab

  • Details: all their links (with short links), revenue share, totals and bank details. Copy All copies everything.
  • Edit: change anything except the ID. Then Save Affiliate.
  • Payouts: jumps to Payouts with this affiliate picked.
  • Delete: removes the affiliate and their payout history. Can't be undone.
  • Show only affiliates missing a Site Nr: tick to find the ones to fix.
  • Looking for one affiliate? Type part of the name, ID, Site Nr or email in the search box. Pick Agent affiliates, Property affiliates or Channel properties in the list next to it to see just those.

Make short codes for everyone

  1. Scroll to Generate short codes for every affiliate.
  2. Tap Check now. Read the list.
  3. Tap Generate short codes. Safe to run again; nothing is doubled.

📝 Applications

  1. Tap Applications. In Notify these email addresses when a new application is submitted (separate several with commas), type the address(es) and tap Save (once).
  2. Tap View details on an application.
  3. Contact the person. Set the status to Contacted.
  4. When you say yes, set it to Approved.
  5. Go to Affiliates and add them (it isn't done automatically).
The status is only a label for you. Nothing is emailed to the applicant.

📣 Default Hooks (the offers on every front store)

What they are: the shared offers. Every affiliate hook on "Let admin manage" shows these, with the affiliate's own booking link. Front stores show 6 at a time (1 big, 2 medium, 3 small); the rest take turns every 6 seconds.

Make a default hook (the easy way)

  1. Tap Default Hooks.
  2. Tap Open the hook builder (the teal card).
  3. Make the hook there, then use Load to hub and pick a Default Hook, or + New hook (see the hook builder guide).
  4. Back in admin, refresh. Find that Hook card.
  5. Choose Place on front stores: Rotates with the others, or Fixed: level 1 (big, top), Fixed: level 2, left / right, or Fixed: level 3, left / middle / right.
  6. Tap Save default.
Hooks loaded from the hook builder get their Promotion ends date from the flyer's end date (Flyer to). Change the date in the hook builder: each Publish again sends it to the hub again (and overwrites a date typed in admin). Event flyers arrive as Hook type "Event / festival"; that's expected.

Make or fix a default hook by hand

  1. Need a new card? Tap + Add a hook at the bottom.
  2. Leave Hook type on Property / resort stay.
  3. Tap 🔗 Build booking link. Pick the place (Country › Province › Region › City › Suburb › Property) and the dates. Tap Fill in booking link.
  4. Landing page: tap 🔗 Build landing page link, or 📄 Upload PDF instead (the PDF link still needs Save default).
  5. Picture: tap Upload image (square, under 4 MB). It saves straight away.
  6. Or tap ✨ Auto-build from property or area, type a property or area in Property name or area (or tick places under 🌳 Browse properties by location), tap Generate, pick up to 4 photos and tap Use this draft.
  7. In that tree, tap Units ▸ next to a property to see its unit types and how many each sleeps.
  8. Set the place and end date. Tap Save default.
  9. Optional: tap 📣 Post to Facebook (Avante Travel Page). A box shows the exact picture and words. At the top, choose Static — one picture or Carousel — swipe cards (the chosen one has a ✓). Tap Post now (it goes public straight away) or Cancel. Carousel needs the hook's Carousel ad step filled in and the landing page published again; up to 5 cards are posted.
Links (also a PDF link), place and end date need Save default. Pictures, Auto-build photos and "Clear hook" save straight away. After Clear hook, reload the page before saving that card again. For hooks you make by hand, keep Hook type on Property: "Event / festival" hides the link fields.

The tool cards at the top

The first five work the same: tap Check now, read the list, then tap the button to apply. Nothing changes before that.

  • Check for collapsed booking/landing links → Apply fix: fixes hooks whose booking and landing links are the same.
  • Move saved booking links to the holiday builder → Move to the holiday builder: changes old Stock Network links to holiday builder links with the location tree.
  • Check for misattributed booking links → Apply fix: fixes affiliate hooks that credit the wrong affiliate.
  • Switch every affiliate to "Let admin manage" → Switch to admin-managed: puts every affiliate hook back on your content (theirs is kept).
  • Clear all booking links (red) → Clear all booking links: empties every booking link. There's no second question, so be sure.

Flyer contact info is a form: type the Contact phone number and Contact email address and tap Save contact info.

A hook shows on front stores until its Promotion ends day (South African time). No date? The booking link's check-out date is used. If an affiliate fixes their own hook in a place, theirs wins over yours on their store.

💰 Payouts

  1. Get the revenue report (Stock Network for accommodation, Impact.com for flights).
  2. Tap Payouts and pick the affiliate in Select an affiliate.
  3. Pick the Revenue channel.
  4. Type the Period (for example "October 2026") and the Revenue for this period (R).
  5. Tap Add Revenue Entry. The amount owed is worked out for you.
  6. Get their bank details: Affiliates → Details.
  7. Pay them from your bank (the hub doesn't move money).
  8. Tap Mark Paid on the entry.
Wrong entry? Tap Delete: the totals fix themselves. The share used is the one set when the entry was added.

🏆 Leaderboard

  1. Tap Leaderboard.
  2. Pick Rank by: Total Turnover or one channel.
  3. Read the ranking. Nothing to change here.
This ranking uses the revenue typed in Payouts. The Bookings tab has its own ranking from Stock Network reports.

📥 Bookings (import Stock Network reports)

  1. In Stock Network: Reports → Reservation Detail Listing → export as CSV.
  2. In admin tap Bookings, choose the file, and tap Upload Report.
  3. Read the result: new, updated, unchanged, skipped.
  4. Pick a Category and Period to see the leaderboard and the full breakdown.
Uploading the same dates again is safe. "Skipped" means no affiliate has that Site Nr: fix it in Affiliates → Edit and upload again. Affiliates see these numbers on their My Dashboard.

💬 WhatsApp Messaging (booking alerts)

What it does: when a Stock Network booking email arrives, it's posted to the affiliate's WhatsApp group, and the guest gets a confirmation on WhatsApp.

  1. Tap WhatsApp Messaging, then Edit Routing on the affiliate's row.
  2. Type a Booking email alias, for example jeanl1967+name@gmail.com.
  3. Put that same address as the notification email on the affiliate's Stock Network site.
  4. Add recipients: tap Fetch My Groups and pick a group, and/or type a number and tap Add (up to 10).
  5. Tap Test on each recipient.
  6. Tick which statuses to send: Request, Booked, Confirmed, Paid.
  7. Tap Save Routing.
  8. After the next booking, check Recent Activity (Sent or Failed).

🏡 Property Listings (onboarding forms)

Set up a property (step by step)

  1. Tap Property Listings. Type part of the property's name (or the owner, place or Site Nr) in the search box. Pick a status next to it to see only Requested, Listed or Rejected.
  2. Tap Set up on the property.
  3. The pop-up opens on What's outstanding: what is left, in the order it needs doing.
  4. Tap Go there on the first line. That step opens on the right.
  5. Do what it says, using the buttons in the step. Everything saves as you go.
  6. Tap Next step for the next one, or tap any step on the left.
  7. Each step shows Done, Your turn, Owner's turn, Waiting on Stock Network or Not yet.
  8. When every step is done (the owner's password doesn't count), open Go live and tap Go live. The listing shows Listed.
A channel property (NightsBridge, eRes) has 8 steps: The request, Site Nr and set-up sheet, Check the site on Stock Network, Location, Connect it, Reviews, The owner's part, Go live. A property with no channel manager has 10: The request, Listing details, Location, Rates and calendar, Set up on Stock Network, Connect it, Reviews, Channels (iCal), The owner's part, Go live.

What each step's buttons do

  1. Check the site on Stock Network: compares what was sent (BBID, name, Site Nr) with what Stock Network made. Right? Tap Yes, this is the right site. Wrong? Tap Wrong site: ask Stock Network and say what's wrong.
  2. Location: Check the pin with Google places it in the hub tree.
    1. Look at the Pin. Is it on the property? Then leave it.
    2. Stock Network's names in orange? You don't type anything: the hub's names are the right ones.
    3. Tap Send the hub's names to Stock Network. The step turns Done.
    See Check the pin with Google again? The District still has the district's name. Tap it first; the hub then finds the local municipality.
    Only if the pin is in the wrong place: tap Pin in the wrong spot? Move it.
  3. Connect it: Paste the Avante login opens the Activate pop-up on the login step.
  4. Reviews: tap the stars for the star rating. Get the rating link fetches it from the review app.
  5. Channels (iCal): tap Copy next to each Avante link and paste it into that channel's calendar import. Paste the channel's own calendar link (ends in .ics) in the box under it. Tap Save the links, then Check channels now. Channel bookings go onto Avante by themselves. Only one that couldn't be added shows below, with the reason: fix it and tap Add to Avante. Only dates the owner closed on a channel (no guest)? Tap Not a booking: it goes off the list and stays off.
  6. The owner's part: Send a reminder emails the owner what's left, with their login link.
    Only the password left? You can still go live. The owner chooses it with Forgot your password? when they first log in.
  7. Bigger jobs (the files for Stock Network, rates, moving the pin) open the listing on top. Close it to come back; the steps check again.
Every property at once: tap What's outstanding? (all properties) next to Refresh. The ones waiting on you are first. Go there opens that property on that step.

Onboard a new property yourself (no affiliate yet)

  1. Tap Property Listings, then + Onboard a new property. The form opens in a new tab.
  2. Go through the 8 steps (see the onboarding form guide). Leave Site ID (affiliate number) — comes later empty.
  3. Tap Submit Listing for Review. It shows up in the list below.
  4. Allocate the Site Nr: tap View, type the StockNetwork Site Nr and tap Save Changes. Now the Stock Network files download (see Send a new property to Stock Network below).

Go live on the hub (after Stock Network sets up the site)

  1. Wait for Stock Network to give you the Site ID and the API credentials for the site.
  2. Create the affiliate in Affiliates with the Site ID as its affiliate number. Tick its type.
  3. Tap Property Listings, then View on the listing.
  4. Type the Site ID in Site ID (affiliate number) — from SN after the Site Nr, for going live.
  5. Has Stock Network given you the property's ResortID? Type it in Stock Network ResortID. The property can then connect in its hub straight away, even before Stock Network's property list shows it.
  6. Tap Save Changes.
The Stock Network files don't need the Site ID, so you can send them before you have it.

Properties already on Stock Network (The Dunes, Silver Ranch …)

A channel property (NightsBridge or another channel manager)? Use Activate a channel property: see Add a NightsBridge property.

Pick from the list

  1. In the same card, tap Show properties. It lists every property connected in Property Affiliate, and every Channel Property Affiliate.
  2. Tap Create listing next to the property. The listing opens, filled in from what the hub has: name, Site Nr, Site ID, place names from the location tree, coordinates, check-in/out, units and how many each sleeps, email and phone.
  3. At the top of the listing a box says Stock Network doesn't have these — please fill in: and names what is missing. Those boxes have a thick dashed border. Fill in only those, then tap Save.
  4. Later, tap Pull again from Stock Network in that box to fill any empty boxes again. It never changes what is typed.
  5. Under Let the property complete its listing, check the address in Email the edit link to (several: separate with commas) (it is filled in from Send Avante's emails about this listing to) and tap Email the edit link. (Or tap Copy the link and send it yourself.)
  6. The property opens the link, fills in what's missing (owner name, photos, amenities, policies, rates…) and taps Save changes on step 8.
  7. Want to fill it in yourself? Tap Open full form to edit (units, amenities, rates).
  8. When it's complete, send it to Stock Network under Send the files by email. The email says Updated property details for Stock Network. If the property's rates come from NightsBridge, set Rates file to Don't send.
  9. Already has a listing? The card shows Open listing (P-…) instead.

Channel Property Affiliates (NightsBridge and other channel managers)

  1. First, in Affiliates, tick Channel Property Affiliate and type its Site Nr.
  2. In Property Listings, tap Show properties. It shows Channel property next to the name. Tap Create listing.
  3. The listing is filled in from Stock Network. It shows the commission (15% + VAT; own bookings Franchisor 5.75% / Franchise 11.5%) and that guests pay through Avante's payment gateway.
  4. Email the edit link as above. The property has no calendar or rates to fill in.
  5. In Send the files by email, the rates file can only be Don't send: their rates come from the channel manager.
  6. The property connects in its hub (Channel Property) with its Stock Network login, Site Nr and Site ID, like any property affiliate. It then sees only Bookings and Reviews; guests always pay on the Stock Network payment page.
  7. Ready for Activities? In Affiliates, tap Edit on its row. Under Channel Property: also give them, tick Activities. Tap Save Affiliate. It sees it the next time it opens its hub. Untick to take it away again.
  8. No front store for a channel property. In Affiliate Marketing it copies its Promotions embed link — no header, for embedding on your own website and puts it on its website. Every offer there books through the hub's booking links, so the hub only books for a channel property through hook builder links.
  9. In Stock Network, open the site's Rates tab. On the MANUAL row set Franchisor to 5.75 and Franchise to 11.50, and tick it. Tap Save. Leave the other rows as they are.
Untick Channel Property Affiliate (or tick Property Affiliate) and the property gets the full Property Affiliate screens again the next time it opens the hub.

Requests from the "List your property" page

  1. A property fills in the List your property page. You get an email: Listing request: …. It says whether the property is already on Stock Network, which Site Nr it got, and whether it ticked Property Affiliate.
  2. Not on Stock Network yet? The hub has already given it the next Site Nr and emailed Stock Network's sheet. See Site Nrs.
  3. A listing is made only when the property ticked I also want to become an Avante Property Affiliate. If the hub found its BBID in its Stock Network list (the External Resort Code column), the listing is filled in from Stock Network.
  4. Tap Property Listings and View on the request (status Requested). Check it.
  5. Wait until Stock Network has set the site up and sent the Site ID. Then tap Email the edit link so the property can complete it. It never gets the link before you've checked it.

Place names always come from the hub location tree

  1. A listing made from Stock Network takes only its coordinates. Its country, province, region, town and suburb come from the hub location tree, never from Stock Network.
  2. No coordinates, or Google couldn't place them? The listing says Not placed in the location tree yet and its place names stay empty. Type the Latitude and Longitude, tap Save Changes, open the listing again with View, then tap Look up again.
  3. The Stock Network files you send carry the tree's place names, so Stock Network's location is corrected too.

Rates from a channel manager (other properties)

  1. A property already on Stock Network whose rates come from NightsBridge (e.g. The Dunes)? Open its listing.
  2. Under Let the property complete its listing, tick Rates and availability come from a channel manager. The form then skips the calendar and rates, and no rates file is sent.
Each unit from Stock Network becomes its own unit type with 1 unit. If several units are the same type, the property can join them in step 5 (one row, with the number of units).

Review a listing

  1. Once: type the address(es) in Notify these email addresses when a new listing is submitted (separate several with commas) and tap Save. New listings and listing requests are emailed to every address there.
  2. Tap Refresh. Tap View on a listing.
  3. Read the top rows: Coordinates checked with Google, Filled from screenshots, and Rates (rack → SN) per season (with any weekend rate and closed nights).
  4. Check and correct the details. Several owner or property emails? Separate them with a comma.
  5. Someone else handles the property's bookings? Fill in Contact person, Contact phone and Contact email (several: separate with commas).
    These contact details also show in the property's own hub. A change here shows there, and the other way round.
  6. Pick who gets Avante's emails in Send Avante's emails about this listing to: Both the owner and the contact person, The owner only or The contact person only.
  7. Set Status to Listed, type the StockNetwork Site Nr, and tap Save Changes.

Edit everything (units, amenities, rates)

  1. Tap View on the listing.
  2. Under Files and Stock Network, tap Open full form to edit (units, amenities, rates). The full form opens in a new tab.
  3. Change anything in any step. Use Later ▶ on the calendar for rates up to 24 months ahead.
  4. Go to step 8 and tap Save changes.
  5. Back in admin, open the listing again and tap History to see every change: when, who (owner or admin) and the old values.

Send a new property to Stock Network

  1. Tap View on the listing. Type the StockNetwork Site Nr you allocated and tap Save Changes. The files won't download without it. The Site ID isn't needed.
  2. Under Files and Stock Network, tap Property file for SN (.xlsx). It has the property, each unit type with how many units and how many it sleeps, and the rates, with the Site Nr in it.
  3. First time: tap Rates file — all future (.xlsx) (or .csv). It has every rate from today onwards in Stock Network's stock upload format.
  4. Email the files to Stock Network. Tap Save Changes so the Site Nr is kept.
  5. Tap Mark rates as sent to SN.

Send the files by email

  1. Tap View on the listing. Type the StockNetwork Site Nr (below the status) if it's not there yet.
  2. Under Send the files by email, type the address in Send to. Several addresses? Separate them with commas. The last address you used is filled in for you.
  3. Tick Property file (.xlsx) if Stock Network must create the property. It includes the amenities, activities and experiences, and the bank details of the affiliate linked to the listing (from its Account Details in the hub).
  4. Pick the Rates file: All future rates the first time, Only new/changed after that, or Don't send. Pick As: .xlsx, .csv or both.
  5. Type a Message if you like (e.g. "Please create this property on Site Nr 6020").
  6. Leave Add a link to the photos ticked. The email gets a link to a page with every photo, full size, and a Download all photos (.zip) button for Stock Network.
  7. Leave After sending, mark the rates as sent to SN ticked, so next time "Only new/changed" leaves these rates out.
  8. Tap Send email. It says Sent ✔, and the Site Nr is saved on the listing.
  9. Open Email log to see every send: date, address, Site Nr, the files and the message. A failed send shows in red with the reason; nothing is marked as sent.
The property file has the affiliate's bank details. Send it only to Stock Network's addresses. No bank details yet? The columns stay empty: ask the affiliate to fill in Account Details in the hub.
The email comes from bookings@go.avantetravel.co.za with the files attached. It's also written in the listing's History.

Photos of a listing (add, delete, photo link, hook builder library)

  1. Tap View on the listing. Scroll to Photos.
  2. To add photos: tap + Add photos and pick them. Big photos are made smaller by themselves. Wait until the list reloads.
  3. To delete a photo: tap Delete under it, then OK.
  4. The photo link in the Stock Network email shows the property's photos first, then each unit type's under its own heading, always as they are now. You don't need to send it again after a change; just tell Stock Network.
  5. Under the photos it says Hook builder photo library: … of … photos. Saving the listing (by you or the property), sending the email or adding photos saves them there by themselves, filed under the listing, the property (once it has a ResortID) and, for unit photos, the unit type. If some are missing, tap Add photos to the hook builder library.
  6. To do every listing at once (for example the first time), tap Put all listing photos in the photo library next to Refresh above the listings. Safe to run again: nothing is doubled.
Deleting a photo here removes it from the listing and the photo link, but not from the hook builder library (a hook may already use it). Admin can delete it there under Photo library.

Send only new rates to Stock Network

  1. When the owner adds or changes rates, you get an email. Tap View on the listing.
  2. Tap Rates file — only new/changed (…) (.xlsx). The number shows how many seasons are new.
  3. Email it to Stock Network, then tap Mark rates as sent to SN.
Past rates are never sent again, but they stay on record: the property file has a sheet All rates on record with every season marked Past, Sent to SN or Not sent yet.
The owner's own files (ID, proof of ownership, rate sheets, photos) are listed under Files and Stock Network. Tap a file name to download it.
The property accepted the Avante Hospitality Terms & Conditions when it listed; there is no separate agreement to send. To say no, set Status to Rejected and save. Every status change emails the people chosen in Send Avante's emails about this listing to (for a listing sent by an affiliate, "owner" means the affiliate).

Copy a property's content (for testing)

  1. Open Property Listings and scroll to Copy a property's content (for testing).
  2. Type the Site Nr to copy from in Copy from Site Nr (e.g. 6019, Little Gem).
  3. Type the Site Nr to copy into in Into Site Nr (e.g. 3, Property Testing).
  4. Tap Copy, then OK. Wait for All done.
Copied: the listing (description, facilities, unit types, rates, house info), its photos, the front store (words, photos, settings, activities), the place in the location tree and the pin, and the library photos. Not copied: the name, login, units, calendar, bookings, contact details, owner details and documents.
The second property's listing, front store and location are replaced. The first property doesn't change.

🔢 Site Nrs (Stock Network set-up)

What it's for: every property is set up on Stock Network first. Avante gives out the Site Nrs, and this list makes sure no number is used twice. The hub started at 6023.

What happens by itself

  1. A property not yet on Stock Network fills in the List your property page.
  2. The hub gives it the next free Site Nr (status Spare).
  3. Picked Not on a platform? It gets no Site Nr yet. A listing is made and the property gets its Edit my listing link.
  4. When that property's Ready check is all Done and it taps Save changes, the hub gives it the next Site Nr (status Ready to send) and you get an email Listing complete, ready for Stock Network.
  5. Open its listing (Property Listings, View) and use Send the files by email to send it to Stock Network. The Site Nr then shows Sent.
  6. Not finished? The property gets reminders 1, 3, 5 and 10 days after its last save. It can tap Complete later (you get Will complete later) or Let Avante set it up.
  7. Got Please set it up? Open the listing, tap Open full form to edit, and use Read screenshots & documents with the files from the email to fill it in. Then complete the Ready check and save.
  8. It makes Stock Network's Request_pull_area sheet: SiteID, BBID, Name, Contact, Phone No, Email, Description, Area, District, Rate (17.25), TripAdvisor Search Link (empty), Suburb. City2 is left out.
  9. On NightsBridge or eRes: it emails the sheet to the addresses at the bottom of Site Nrs straight away. The status changes to Sent.
  10. The property gets an email with its Site Nr.
  11. Every hour the hub looks on Stock Network for each Sent Site Nr (by Site Nr, else by BBID, else by its exact name near its pin).
  12. Found? The status changes to Set up.
  13. The hub makes the property's affiliate. Its affiliate number is the property's Site ID. It is not connected until the property enters its Avante login.
  14. The property's listing (if it has one) gets its ResortID and Site ID.
  15. The property gets an email You're set up with Avante with its affiliate number and the login link. It taps Forgot your password? to set a password.
  16. You get an email listing what was set up.
  17. Not on a platform? Stock Network's list has no Site ID, so under its status it says Needs its Avante login: tap Activate. No affiliate or email yet.
  18. Got the property's Avante login from Stock Network? Tap Activate on its row. The pop-up Activate a property opens on step 2.
  19. Paste the Username, Client ID and Client secret. Tap Check the login.
  20. Check the email and phone. Tap Next.
  21. Tap Activate. The hub makes its Property Affiliate (number = Site ID), links its listing and connects it.
  22. Check the welcome email. Tap Send. Then Close.
  23. Under its status it now says Waiting for stock. Every hour the hub looks for Avante stock for it, 12 months ahead.
  24. Stock found? It says Ready to go live (stock from …), the listing notes it too, and you get an email Ready to go live.
Don't want to wait for the hour? Tap Check Stock Network now at the top of Site Nrs. The answer shows under the button.
Ticked Property Affiliate? The sheet gets MANUAL Franchisor % 5.75 and MANUAL Franchise % 11.5, and the email asks Stock Network to set the MANUAL row on the site's Rates tab once the site is up. The sheet's Rate stays 17.25.
Area, District and Suburb come from the hub location tree. With a listing: from the listing's pin (grey, can't be typed). Without a listing: from where Google finds the property by its name. If Google can't find it, they stay empty: fill them in and send again (below).
After Check Stock Network now the answer also says Stock Network's list read now: … properties. A WARNING that the hub couldn't save that list means the check still worked, but tell Claude. The hourly check emails you about it once a day.

Check or change a Site Nr, and send it again

  1. Tap Site Nrs. The list shows the highest number first. Failed in Sent to SN means the email didn't go.
  2. Tap Open on the row.
  3. Change what you need (for example Contact, Email, or a Note to Stock Network (in the email)).
  4. Grey Area, District and Suburb? They come from the listing. To change them, open the listing in Property Listings and fix its latitude and longitude.
  5. Tap Save, or Save and send the sheet to Stock Network to email it again. Every email is listed under Emails sent.
  6. Stock Network has created the site but the hourly check can't find it? Not on a platform: tap Activate on the row. It opens on the login step: paste the login and the hub finds the property. On a channel manager: use Activate a channel property.

Reserve a Site Nr by hand

  1. Under Reserve a Site Nr by hand, leave Site Nr empty for the next free one, or type the number (for example one Stock Network already used).
  2. Type the Property name (empty = Spare). Tick Already set up on SN if it is.
  3. Tap Reserve.
Give out Site Nrs only from this list. A number handed out in Stock Network directly isn't known to the hub: reserve it here by hand straight away.

Who gets the sheet

  1. In Email Stock Network's set-up sheet to (separate several with commas), type the addresses. The default is nb@stocknetwork.co.za, admin@avantehospitality.co.za and liason@avantehospitality.co.za.
  2. Tap Save.

Commission for property affiliates (tell Stock Network)

  1. Tap Site Nrs and go to Commission for property affiliates.
  2. Tap Check the list. It shows every property and channel affiliate with MANUAL Franchisor % 5.75 and MANUAL Franchise % 11.5 (the MANUAL row on the site's Rates tab in Stock Network).
  3. Check the list. Tap Email Stock Network. One email with one sheet goes to the set-up addresses above.
  4. It says Sent to … and Last sent shows the date. Channel listings that still said 4.95% are set to 5% at the same time.
New property affiliates don't need this: their set-up sheet already has the two fields. Use it again whenever the commission changes.

🏨 Add a NightsBridge property (start to finish)

What it's for: every step to bring a property that runs on NightsBridge into the hub, from the first contact to its first booking.

The quick way: Activate a channel property

For a property already on Stock Network through NightsBridge (or another channel manager). First get its Avante login (username, client ID, client secret) from Stock Network.

  1. Tap Property Listings.
  2. Under Properties already on Stock Network, tap Activate a channel property. A pop-up opens with 5 steps.
  3. 1 Find the property: type at least 3 letters of its name in Property name. Tap it in the list.
  4. Not in the list? Tap Find it with its Avante login.
  5. 2 Its Avante login: paste the Username, Client ID and Client secret. Tap Check the login. The hub finds its Site Nr and Site ID itself.
  6. Came with Find it with its Avante login and the hub asks for its ResortID? Paste it. It is the last column of Stock Network's resort file.
  7. Check Property name. Tap Use this ResortID.
  8. 3 Contact details: check the Email, Phone and Contact person. They come from the hub, or from Stock Network when the hub has nothing yet. Still empty? Type them: Next works once there is an email. Tap Next.
  9. 4 Activate: tap Activate. The hub makes or links its listing, makes its Channel Property Affiliate (5% + VAT on own bookings, Hook Builder on), gets its rating link from the review app and connects it. Each line shows ✔ when done.
  10. A red NOT connected line? Tap Back, check the login, then tap Try again. The welcome email only comes once it is connected.
  11. 5 Welcome email: check Send to. The Subject and Email show the email filled in for this property: change them here if you want (only for this property).
  12. Tap Send. The property gets the email with its affiliate number and login link.
  13. Tap Close.
The property never needs its Avante login: you connected it in step 4. It logs in to the hub, taps Forgot your password? to choose a password, and finds Hook Builder ↗ and Activities ready.
Back goes to the step before. On a phone the pop-up fills the screen.

Rating link (reviews)

Every property gets a rating link from the review app. It shows the property's Google rating until it has 3 Avante reviews, then Avante's own. It goes to Stock Network in the property file. You don't copy it: Activate and Create the affiliate fetch it.

  1. Tap Property Listings, then View on the listing.
  2. Find the Reviews box. It shows Rating link: open it and what Google said.
  3. It says Is this the property on Google? Check the name and address. Right? Tap Yes, that's it. Wrong? Leave it: the property shows Avante reviews only.
  4. No rating link yet, or you want to check it? Tap Get the rating link (or Check the rating link again).
The Reviews box shows once the listing has its ResortID. The review app adds the property itself if it's new.

Change the welcome email for every channel property

  1. Tap Property Listings and scroll to Channel property welcome email.
  2. Change the Subject and Text. A blank line starts a new paragraph. Put ** around words to make them bold.
  3. Keep the fill-in words where you want them: {property}, {contact}, {siteNr}, {affiliateNumber}, {loginLink}. {loginLink} must stay.
  4. Tap Save.
Want the original back? Tap Back to Avante's wording.

The property starts it itself

  1. It opens the List your property page, taps NightsBridge, types its NightsBridge BBID Number and taps Submit. You get an email: Listing request: ….
  2. Not on Stock Network yet? The hub gives it a Site Nr and emails Stock Network's sheet (see Site Nrs). When it's set up, use Activate a channel property as above.

Test it once

  1. Make one hook for it in the hook builder and one test booking through that hook link.
  2. Check it reaches NightsBridge marked Avante Hub booking and that payment goes through Avante's payment page.
  3. Check it shows in the property's Bookings in the hub (it shows when Bookings is opened).
A hook-link booking that doesn't show in Bookings: tell the developer. The hub keeps a note of what Stock Network sent, so it can be fixed quickly.

🗺️ Map & Activities

What it's for: what shows on the Explore Map, the location tree, coordinates, and activities. Use Jump to: at the top to go to a section.

Daily check

  1. Tap Map & Activities.
  2. Read the Overview tiles. Tap any tile that isn't 0 to go and fix it.

Add an activity

  1. Go to Add an activity.
  2. Type the Name. Google photos of it come up by themselves under 🖼️ Find photo.
  3. Tap a Google photo to pick it. Or upload your own under Photos (up to 12). You can do both.
  4. Type the area, price, Latitude, Longitude, booking link and description.
  5. Tap Save activity. The photos are saved with it.
  6. Each photo also goes into the hook builder's photo library, tagged with this activity (and its town).
  7. The photo you add last becomes the activity's main photo: front stores and hooks show it first (unless a property or affiliate chose their own).
  8. Check its Location in the list below.

Change an activity's default photo

  1. Open Map & Activities and find the activity in the list.
  2. Under Photos you see its Default photo: the photo front stores and hooks show for it.
  3. Tap Change photo.
  4. Pick one photo: from This activity, the Photo library (type to search the whole library) or From your device.
  5. Tap Use 1 photo. It is now the default everywhere.
  6. Want a Google photo? Tap Google. It searches Google for the activity, then opens the library with those photos. Pick one.
Google photos are kept as a link only (Google's rules). If one ever stops working, the activity gets a new photo by itself.

Refresh a property's unit types

  1. On the Master map, find the property in the tree.
  2. Tap Units ▸ next to it.
  3. Tap ↻ Refresh units at the bottom of its units.
  4. Wait a few seconds. It shows Updated from Stock Network just now.
You only need this when a property changed its units on Stock Network. Otherwise the hub reads new properties within the hour, and every property again every 6 months.

Fix a pin in the wrong place

  1. On the Master map, tap the pin, then Fix coordinates.
  2. Tap Open in Google Maps, right-click the right spot, and click the numbers to copy them.
  3. Paste them and tap Save and place again, then Reload map.

A property with no pin

  1. Go to Find & fix missing coordinates. Pick the list and tap Load properties with no coordinate.
  2. Tap Search, then Use this on the right match.
  3. Can't find it? Tap Can't find it — flag as possibly inactive. Later download the flagged list for Stock Network.

New Stock Network properties (added by themselves)

Every night the hub adds the Stock Network properties it doesn't have yet. Their place in the location tree comes from their pin, like every other property.

  1. Go to Added from Stock Network and tap Refresh list. It says how many last night's sync added, and lists them newest first.
  2. One Avante doesn't carry? Tap Remove from hub on its row, then OK. The nightly sync won't add it again.
  3. Some still not in the tree? Under Location tree, tap Re-run lookup.

A property Stock Network's list leaves out

Bookable on Stock Network, but not in the hub (for example Little Gem @ The Dunes)? Stock Network's list left it out. Its resort file has it.

  1. On Stock Network, export the resort file (Resort Information .csv).
  2. In Map & Activities, go to Added from Stock Network.
  3. Under Add from Stock Network's file, tap Choose Stock Network's resort file (.csv)… and pick the file.
  4. Wait. It says how many properties the file has and lists the ones the hub doesn't have yet.
  5. Check the list. Tap Add.
  6. They now show in the list above with from the file, and get placed in the location tree like every other property.
Properties the hub already has are never changed by the file. One you took out with Remove from hub stays out.
Tell Stock Network too: their list should have it. Until they fix it, the file is the way in.

Location differences with Stock Network

  1. Go to StockNetwork location review and tap Load flagged properties.
  2. For each row: tap Accept suggested coordinate, or type a District / City2 / State correction and tap Save correction.
  3. Under Corrections to send to StockNetwork, tap Download CSV and email it to Stock Network.

Hide a property from the map

  1. Onboarded (listed) property: go to Properties on the map and untick Show on map.
  2. Stock Network property: on the Master map, tap its pin and tap Hide from map.

🧽 SN Cleanup (make Stock Network match the hub)

What it does: builds a file for Stock Network so Country, Area, City, Suburb and coordinates match the hub's location tree. One step at a time; nothing runs until you press that step's button.

  1. Upload: choose the Stock Network Resort Information export (.csv). Pick Test run the first time (10 properties; you can change the number, up to 500). Tap Next → to go on (← Back goes back).
  2. Find coordinates: tap Start lookups. Decide the Unsure ones (Accept / Reject).
  3. Place in hub: tap Save coordinates and place in hub.
  4. Area choice: keep "Replace with the Avante region" (normal).
  5. Build file: tap Build file. Every check must be ✓ (a "!" is a warning and is OK). Download the file.
  6. Check: load the file into Stock Network, wait one night, come back and tap Check now.
  7. All good? Do it again with Everything in the file.
Google lookups cost money; the screen shows the cost before you start. Any ✗ in the checks means: do NOT load that file into Stock Network.

📈 SN Calls (how hard the hub calls Stock Network)

What it does: counts every call the hub makes to Stock Network, so you can see how often it calls and spot when it calls too hard. Times are SA time.

  1. Tap the SN Calls tab.
  2. Pick Last 24 hours, Last 7 days or Last 30 days.
  3. Read the boxes at the top: Calls to Stock Network, Busiest hour, Busiest minute, "Too many" answers, Calls that failed and Average answer time.
  4. Look at Calls per hour. Each bar is one hour. Point at a bar to see its numbers. Amber bars are over your limit or had a "too many" answer.
  5. Scroll down to see Which part of the hub calls, Which property (Site Nr) and Which Stock Network address.
  6. To change when it warns you: under Warn me, type Calls a minute and Calls an hour, then tap Save.
"Too many" means Stock Network itself told the hub to slow down. That is the surest sign. Your own limits are only warnings until Stock Network tells us its real limit (they start at 60 a minute and 1,000 an hour).
The hook builder's calls are counted too. They show as Hook builder · … under Which part of the hub calls. A live price check runs on GitHub and reads several Stock Network pages, but counts as one call. Property calendars show as Property affiliate · ….
The busiest minutes usually come from the availability check (up to 60 properties at once) and the channel sync every 15 minutes.
